# Plan 01-03: Stock/reference baseline

## Objective
Establish the first deterministic full-model reference before custom kernels or model surgery. Measure text and multimodal status honestly, including partial-offload/resource failures and labeled fallback routes.

## Requirements
- REQ-E0-04

## Hypothesis and target
**Hypothesis:** A pinned stock runtime can produce finite, coherent Qwen3.8-27B output at context 2048 using the available NVFP4/4-bit artifact with CPU/RAM offload as required, while exposing whether complete image-text behavior is supported.

**Numeric targets:** deterministic repeated text sample at context 2048; record load/TTFT/prefill/decode, peak VRAM/RAM, and quality sample; attempt one multimodal prompt and classify `complete`, `text-only`, or `blocked` with exact evidence.

## Tasks

### 1. Pin launcher and runtime
- Create `scripts/s03_stock_baseline.ps1` with model path, runtime executable/revision, quant, context, seed, prompt set, offload settings, and output directory as explicit parameters.
- Use Windows-native first; label WSL2 or alternate runtime as a separate route, not a merged measurement.
- Pre-register hypothesis, target, one changed variable, exact command, model hash, and context in `experiments/LOG.md` before execution.

### 2. Run deterministic text baseline
- Use a fixed text prompt and seed with context 2048, warmup plus repeated timed decode.
- Capture output, load time, TTFT, prefill/decode tok/s, VRAM allocated/reserved/peak, RAM peak, and process/runtime versions.
- If the full model cannot load, retain the failure record with numeric constraint, two candidate engineering routes, and cheapest next command.

### 3. Attempt complete multimodal smoke
- Use one fixed image and prompt through the pinned processor/vision path.
- Record visual preprocessing, visual-token count if available, phase timings, peak memory, and output classification; do not call text-only support complete.

### 4. Generate report
- Write `experiments/E0_stock_baseline.md` with exact model/quant/context/command and required Status / Numbers / Next Experiment sections.
- Preserve raw JSON/output under `quality/reference/` or `experiments/raw/` without committing model weights.
