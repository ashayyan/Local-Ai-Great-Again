# Plan 01-05: Clean-checkout reproduction and E0 gate package

## Objective
Make the complete E0 package rerunnable from a clean checkout, with numbered scripts, pinned runtime/model references, machine-readable logs, generated headline tables, and an explicit E0 gate decision. This plan owns the remaining experiment-contract requirements.

## Requirements
- REQ-LOG-01
- REQ-LOG-02
- REQ-LOG-03

## Hypothesis and target
**Hypothesis:** A fresh checkout can regenerate the E0 hardware, manifest, baseline, quality, and ladder reports using numbered scripts and external model/runtime hashes without hand-edited paths or committed large artifacts.

**Numeric targets:** one clean-checkout rehearsal; all E0 scripts run in dependency order; generated reports include run IDs, commands, commit hashes, environment, model/quant/context, warmups/repetitions, speed, latency, VRAM/RAM, quality, failure evidence, and next test; large model files and binaries remain outside git.

## Tasks

### 1. Build orchestration and environment capture
- Create `scripts/s07_run_e0.ps1` to validate prerequisites, register a run, invoke `s01` through `s06` in dependency order, and write `experiments/e0_runs/<run-id>.json`.
- Create `scripts/s08_verify_e0_reproduction.ps1` to run from a clean checkout/worktree and compare expected generated schemas/artifact hashes without requiring model bytes in git.
- Pin runtime revisions and record PowerShell, Python/CUDA/toolchain versions; use explicit absolute/relative path resolution from repository root.

### 2. Enforce run contract
- Ensure every orchestration attempt appends to `experiments/LOG.md`, including missing hardware/model/runtime failures.
- Validate exactly one changed variable for each quant comparison and preserve pre-registered hypotheses and numeric targets.
- Generate or refresh `notes/E0_headline_table.md` from JSON, clearly labelling measured/derived/external/hypothesis values and incomplete gates.

### 3. Reproduction and gate record
- Execute a clean-checkout rehearsal using small/no-download fixtures where full models are unavailable; classify that result separately from the real hardware/model run.
- Create `experiments/E0_gate.md` listing REQ-E0-01–06 and REQ-LOG-01–03, evidence paths/hashes, pass/fork/dormant status, exact numeric constraints, two routes for blockers, revisit trigger, and cheapest next command.
- Do not claim E0 complete until all required evidence is present; preserve unresolved items as explicit failures/next experiments.
